# Foto2PDF

Android telefon için basit bir uygulama: fotoğraf çeker, çektiğin fotoğrafları tek bir PDF dosyasına dönüştürür.

## Nasıl kullanılır (uygulama içinde)
1. "Fotoğraf Çek" butonuna bas, istediğin kadar fotoğraf çek.
2. "PDF Oluştur" butonuna bas.
3. PDF oluşur ve paylaşma menüsü açılır (WhatsApp, e-posta, dosyalara kaydet vb.).

## APK nasıl indirilir
Bu depo GitHub'a yüklendiğinde, `.github/workflows/build.yml` otomatik olarak çalışır ve APK dosyasını üretir.
Üretilen APK'yı indirmek için:
1. GitHub'da bu depoya git.
2. Üstteki "Actions" sekmesine tıkla.
3. En üstteki (en yeni) çalışmaya tıkla.
4. Sayfanın altındaki "Artifacts" bölümünden "Foto2PDF-apk" dosyasını indir.
5. İndirilen zip'i aç, içindeki `app-debug.apk` dosyasını telefonuna aktar ve kur.

Not: Telefonunda "bilinmeyen kaynaklardan yükleme" iznini açman gerekebilir.
